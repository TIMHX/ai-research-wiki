# Mamba-2: Transformers are SSMs — Generalized Models and Efficient Algorithms Through Structured State Space Duality

**Authors:** Tri Dao (Princeton), Albert Gu (CMU)
**Published:** May 2024 (arXiv)
**Venue:** ICML 2024
**Citations:** 2,000+

## Core Insight: State Space Duality (SSD)

The paper reveals that SSMs and linear attention are two views of the same mathematical
object — a **semi-separable matrix transformation**. This "duality" unifies:

- **Recurrent view (SSM):** O(N) computation with constant-size state, good for inference
- **Attention/Matrix view:** O(N²) computation with pairwise interactions, good for training

SSD leverages the best of both: train with the matrix view (high parallelism on GPUs),
infer with the recurrent view (constant memory).

## Key Improvements over Mamba-1

1. **Multi-head SSMs:** Like multi-head attention, SSD splits the state into multiple heads,
   each with its own dynamics. Typical: d_state=64 or 128 per head.

2. **Faster Training (2-8×):** By reformulating the selective scan as structured matrix
   multiplications, Mamba-2 achieves 2-8× faster training than Mamba-1 on modern GPUs.
   This closes the training cost gap with FlashAttention-based Transformers.

3. **Tensor Core Friendly:** The matrix formulation maps naturally to tensor core operations,
   unlike Mamba-1's custom scan kernel.

4. **Simplified SSM Core:** The inner SSD module is remarkably concise — Listing 1 in the paper
   shows the core algorithm in ~30 lines of PyTorch.

## Architecture

```
Mamba-2 Block:
  Input → LayerNorm → Linear Projections (X, B, C) → Conv1D (kernel=4) → SiLU →
  Multi-head SSD → RMSNorm → Output Projection → Residual
```

**Key parameters:**
- `d_state`: 64 or 128 (larger than Mamba-1's 16)
- `headdim` (SSD): 64
- `chunk_size`: configurable (trades memory for throughput)
- `expand`: 2

## Mamba-2-ATTN Variant

The paper also introduces **Mamba-2-ATTN**, a hybrid that replaces some SSD layers with
self-attention. This captures the benefits of both: attention's powerful pairwise interactions
for key layers + SSD's efficiency elsewhere.

## Performance

Trained on Pile, 300B tokens. Mamba-2-2.7B matches or exceeds Transformer++ of same size
on standard LM benchmarks (LAMBADA, HellaSwag, PIQA, ARC, WinoGrande, OpenBookQA).

## Related: Mamba-2-Hybrid / TransMamba

Subsequent work (2024-2025) explored interleaving Mamba-2 + attention layers, leading to
architectures like Jamba (AI21 Labs) and TransMamba.
