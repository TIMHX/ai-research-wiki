# Mamba-3: Improved Sequence Modeling using State Space Principles

**Authors:** Aakash Lahoti, Kevin Y. Li, Berlin Chen, Caitlin Wang, Aviv Bick,
J. Zico Kolter, Tri Dao†, Albert Gu† (CMU + Together AI)
**Published:** March 2026 (arXiv)
**Venue:** ICLR 2026

## Overview

Mamba-3 is the third generation of the Mamba SSM architecture. While Mamba-2 focused on
speed via SSD (matrix formulation), Mamba-3 focuses on **model quality** — pushing SSM-based
language models to match or exceed Transformer performance at scale.

## Key Innovations

1. **MIMO (Multi-Input Multi-Output) SSMs:** Previous SSMs process channels independently
   (one SISO SSM per channel, then mix). Mamba-3 introduces MIMO SSMs that process multiple
   channels jointly, improving expressiveness with a tunable rank parameter (`mimo_rank`).
   This creates a richer state space without proportional compute increase.

2. **Improved Initialization:** Better parameter initialization strategies drawn from
   SSM theory (HiPPO variants), improving training stability and convergence speed.

3. **SSM Head Architecture:** Redesigned the multi-head structure — `headdim=64` with
   `d_state=128`, optimized for modern GPU architectures.

4. **Output Projection Norm:** Optional `is_outproj_norm` flag adds normalization after
   the SSM core, found to improve training stability at larger scales.

## Architecture Specs

```python
model = Mamba3(
    d_model=dim,
    d_state=128,        # SSM state size (up from 64)
    headdim=64,         # SSD head dimension
    is_mimo=True,       # Use MIMO mode
    mimo_rank=4,        # MIMO rank
    chunk_size=16,      # BF16: 64/mimo_rank
    is_outproj_norm=False
)
```

**Parameter count:** ≈ 6 × d_model² (vs 3 × d_model² for Mamba-1）

## Relationship to Mamba-2

Mamba-3 builds on Mamba-2's SSD framework. The core matrix formulation stays the same,
but Mamba-3 adds MIMO SSMs on top. Think of it as Mamba-2 with richer state dynamics.
